# Chat Development Sessions

## Estructura
- `sessions/` - Archivos JSON de conversaciones completas
- `summaries/` - Resúmenes por sesión con decisiones clave

## Nomenclatura
- Sesiones: `YYYY-MM-DD-tema.json`
- Resúmenes: `YYYY-MM-DD-tema-summary.md`

## Uso
1. Copiar archivo `chat-history-*.json` a `sessions/`
2. Crear resumen en `summaries/`
3. Commit cambios
